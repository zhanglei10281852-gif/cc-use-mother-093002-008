# 跨境教育技术集成试点

面向东盟合作院校试点的智能教学组件集成管理服务，解决组件声明不一致、
演示成功即被当作可推广成果、适配配置无法追溯的问题。

## 能力概览

- **制品登记**：组件制品摘要不可变（重复登记须摘要一致，冲突即拒绝），
  能力声明（课程数据格式、语言包、运行能力）与依赖契约随登记固定。
- **本地化适配方案**：按学校建立，依据制品能力声明校验语言包、数据格式
  与运行特性；新方案取代旧方案并递增版本，试点记录锁定所用方案。
- **阶段门控**：兼容检查 → 小规模验证 → 观察期 → 推广评审，逐阶段收集
  带过期时间的证据；关键指标缺失或证据过期时不得晋级；失败可回退前一阶段。
- **幂等试点**：同一制品与学校的重复试点请求复用原记录。
- **限时风险豁免**：按指标类别由不同角色批准（兼容/质量/运营/治理），
  过期自动失效。
- **严重问题处置**：一次上报即冻结相关组合、列出全部采用方并启动回撤。
- **持久化恢复**：全部状态写入 JSON store（原子替换），操作员重启进程后
  可继续原试点。
- **查询端点**：`release_decision`（放行/阻断证据）、`adaptation_diff`
  （学校间适配差异）、`recall_scope`（当前回撤范围）。

## 运行测试

    python3 -m unittest discover -s tests -v

## 编译检查

    python3 -m compileall -q src tests run_cli.py

## 命令行冒烟

    python3 run_cli.py

冒烟脚本演示从制品登记到严重问题回撤的完整流程，并模拟进程重启后
继续原试点；演示数据写入 `var/pilot-store.json`（已加入 .gitignore）。
